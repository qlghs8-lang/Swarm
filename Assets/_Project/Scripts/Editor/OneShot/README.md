# OneShot — 1회용 아트 연결 도구

이 폴더의 스크립트는 **이미 실행이 끝난 1회용 셋업 도구**입니다.
각 파일은 `Swarm/Art Test/...` 메뉴 항목 하나를 제공하며, 씬·프리팹에
스프라이트·머티리얼·Animator를 연결하는 작업을 수행합니다.

## 다시 실행하지 마세요

- 실행 결과는 이미 `Game.unity` / `TestStage.unity` / 프리팹에 저장되어 있습니다.
- 스크립트에는 씬 경로와 오브젝트 이름이 하드코딩되어 있습니다.
- 이후 손으로 조정한 연결이 있다면 **덮어써서 되돌립니다.**

새 아트를 연결할 때는 이 스크립트를 재실행하지 말고, Unity 인스펙터에서
직접 연결하거나 해당 작업만 하는 새 도구를 작성하세요.

## 삭제해도 되는가

예. 어떤 런타임 코드도 이 폴더를 참조하지 않습니다. 남겨둔 이유는
"어떤 에셋이 어디에 연결되어 있는지"의 기록으로서의 가치 때문입니다.
