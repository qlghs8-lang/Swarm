# Swarm

**8방향 이동 로그라이크 서바이버** · Unity 6000.4.3f1 (URP) · C#

> 시간 기반 웨이브로 몰려오는 적 무리(swarm)를 헤쳐나가며 레벨업 카드로 성장하고, 10분 뒤 등장하는 보스를 처치해 라운드를 클리어하는 서바이버 액션. 원래 1개월 스코프로 시작했지만, 포트폴리오 볼륨을 위해 캐릭터 시스템·직업별 무기·무기 진화·상점·보스전 등을 원 스코프 밖으로 계속 확장 중.

---

## 게임플레이 흐름

```
Title 화면(캐릭터 선택/해금 + 골드 상점) → 게임 시작
                    ↓
플레이어 이동(8방향) → 적 처치 → 경험치·골드 오브젝트 드랍(랜덤 산포) → 습득
                    ↓
    경험치: 레벨업 카드 3장 중 1장 선택 (무기 강화 카드 + 런 패시브 카드가 한 풀에서 섞여 나옴)
                    ↓
        시간 기반 웨이브로 적 3종 지속 스폰 (시간 흐를수록 스폰 속도·적 체력/방어 증가)
                    ↓
        3/6/9분마다 대규모 웨이브(WAVE 안내) → 10분에 보스 등장(BOSS 안내)
                    ↓
      보스 처치 → 클리어 결과 화면 / 도중 사망 → 게임 오버 결과 화면 → "다시 시작" 또는 "타이틀로"
                    ↓
골드: 적 처치 시 낮은 확률로 드랍 → 세션 간 유지(PlayerPrefs)
      → 타이틀 화면 상점에서 영구 패시브 구매/캐릭터 해금 (다음 판부터 적용)
```

## 캐릭터 & 무기

각 캐릭터는 **자기 전용 무기 3개**(시작 무기 1개 + 레벨업 카드로 얻는 무기 2개)를 갖는다. 무기는 캐릭터 간에 공유되지 않으며, 데미지는 그 캐릭터의 주 능력치(공격력 또는 마력)를 따른다. 세 캐릭터는 전투 스타일뿐 아니라 기본 스탯(체력/방어력/이동속도/쿨타임 감소)도 서로 다르게 설계되어 정체성이 나뉜다.

| 캐릭터 | 해금 | 주 능력치 | 정체성 | 시작 무기 | 카드 무기 1 | 카드 무기 2 |
| ------ | ---- | --------- | ------ | --------- | ----------- | ----------- |
| 전사   | 기본 해금 | 공격력 | 근거리 딜탱 — 체력·방어력 높음, 스킬셋이 단순한 대신 맷집으로 버팀 | 전방 베기 (근접 부채꼴, 실제 판정과 정확히 일치하는 시각 인디케이터) | 공전검 (플레이어 주위를 도는 검, 투사체 증가 패시브를 먹으면 검이 늘어나고 항상 균등 배치) | 흡혈 강타 (최근접 적 단일 고데미지 + 입힌 피해 일부만큼 회복) |
| 궁수   | 골드 100G | 공격력 | 유틸형 — 이동속도·쿨타임 감소 보너스, 체력·방어력은 중간 | 활쏘기 (범위 내 감지된 적 수만큼 동시에 한 발씩 발사) | 화살비 (논타겟 부채꼴 다발 투사체) | 구르기 (액티브 — 온스크린 버튼/스페이스바로 발동하는 짧은 무적 회피 이동) |
| 마법사 | 골드 150G | 마력   | 범위 딜러 — 잡몹 처리에 강하지만 단일 대상엔 약함, 체력·방어력 낮음 | 낙뢰 (범위 내 여러 적 머리 위로 번개, 레벨업할수록 동시 타격 인원 증가) | 화염구 (관통형 대형 투사체) | 힐 (일정 주기마다 체력 회복) |

- 모든 무기는 `LevelableWeapon` 추상 클래스를 상속한다 — 레벨(최대 8)이 오를수록 데미지가 늘고 쿨타임이 줄며, 레벨업 카드를 뽑으면 그 무기의 레벨이 오른다. 데미지 없는 유틸리티 무기(구르기, 힐)도 같은 프레임워크를 그대로 써서 "레벨↑ = 쿨타임↓"만 적용받는다.
- 무기가 레벨 8(만렙)에 도달하면 다음 레벨업 때 그 무기를 완전히 대체하는 **진화 카드**가 강제로 등장한다(자세한 내용은 아래 "무기 진화" 참고).
- `CharacterDefinition`이 캐릭터 적용 시 그 캐릭터가 실제로 들고 있는 무기들만 "이번 판에 등장 가능"으로 표시하기 때문에, 다른 캐릭터의 무기가 레벨업 카드에 섞여 나오지 않는다. 같은 시점에 캐릭터별 기본 스탯 보너스(체력/방어력/이동속도/쿨타임 감소)도 함께 적용된다.
- 활쏘기·화염구처럼 "범위 내 여러 적에게 동시 타격"이 필요한 무기와, 화살비처럼 "논타겟 부채꼴"이 필요한 무기는 서로 다른 클래스로 완전히 분리되어 있다 — 같은 발사체 개념이라도 겨냥 방식(멀티 타겟 vs 고정 스프레드)이 다르면 로직을 억지로 하나로 합치지 않는다.
- 투사체 개수·범위 크기를 늘리는 런 패시브는 모든 무기가 공용으로 소비하는 범용 스탯(`ProjectileCountBonus`/`AreaSizeBonus`)이라, 무기별로 별도 구현 없이 값만 읽어 쓴다.

## 무기 진화

9개 무기 전부 레벨 8(만렙) 도달 시 진화 카드로 완전히 다른 무기로 전환된다. 진화 후엔 레벨 1부터 새로 성장하며(기존 레벨과 무관), 원본 무기는 비활성화(`Retire()`)된다.

| 캐릭터 | 원본 | 진화 | 핵심 변화 |
| ------ | ---- | ---- | -------- |
| 전사 | 전방 베기 | 콤보 어택 | 베기→찌르기→내려찍기 3연속 자동 컴보(순서대로 데미지 증가, 레벨업 시 데미지 증가+주기 단축) |
| 전사 | 공전검 | 소드 체이싱 | 평소엔 공전, 사거리 내 적 감지 시 스치듯 날아가 타격 후 다른 적으로 이동 반복(투사체 수만큼 서로 다른 적을 노려 한곳에 뭉치지 않음), 화면 밖으로 나가면 즉시 텔레포트 귀환 |
| 전사 | 흡혈 강타 | 레이지 | 이 스킬로 처치할 때만 공격력·최대체력 영구 스택 획득, 화면 하단에 스택 수 표시 |
| 궁수 | 활쏘기 | 집중 | 여러 적에 한 발씩 분산 → 한 적에게 전탄 집중(3발 시작, 5레벨까지 8발로 증가), 연속 발사(버스트) |
| 궁수 | 화살비 | 난사 | 관통(데미지 감소 없음, 대신 기본 데미지 낮춤) + 360도 회전 발사로 전환 |
| 궁수 | 구르기 | 맹독 구르기 | 구른 자리에 독가스 장판을 남겨 도트딜 + 방어력/이동속도 감소(발동 방식은 원본과 동일하게 액티브 유지) |
| 마법사 | 낙뢰 | 아이스 볼트 | 범위 다중 타격 → 실제 투사체로 전환, 맞은 적 기준 주변 적으로 연쇄 전이(체인 라이트닝), 피격 시 10% 확률로 1초 빙결 |
| 마법사 | 화염구 | 익스플로전 | 대상 위치로 운석이 대각선으로 낙하해 착탄 피해 + 화염 장판 생성(밟으면 발화, 장판을 벗어나도 몇 초간 도트딜 지속) |
| 마법사 | 힐 | 블레싱 | 회복 + 짧은 시간(3초) 마력/방어력/마법관통력 증가 및 다른 무기 쿨타임 감소 버프 부여(블레싱 자신의 쿨타임은 이 버프에서 제외해 무한 루프 방지) |

- 진화 여부와 무관하게 같은 UI/입력이 계속 작동하도록 인터페이스로 분리했다 — 예: 구르기/맹독 구르기 둘 다 `IActiveRoll`을 구현해서, 회피 버튼 UI는 "지금 활성화된 쪽"을 몰라도 되고 진화 전후로 끊김이 없다.
- 독가스 장판·화염 장판처럼 지속형 범위 디버프/도트 효과는, 여러 개가 겹쳐도 도트딜·디버프가 중복 적용되지 않고 "하나만 맞은 것"과 동일하게 처리된다 — 효과의 소유권을 장판이 아니라 적 쪽의 단일 상태(`EnemyHealth.ApplyPoison`/`ApplyBurn`)로 옮겨서, 몇 개가 동시에 겹쳐 신호를 보내도 데미지 틱은 하나만 나간다.

## 스탯

| 스탯 | 획득 경로 | 설명 |
| ---- | --------- | ---- |
| 공격력 / 마력 | 런 패시브 + 영구 패시브 | 캐릭터의 주 능력치에 맞는 쪽이 자동으로 적용 |
| 최대 체력 | 런 패시브 + 영구 패시브 | |
| 이동속도 | 런 패시브 + 영구 패시브 | |
| 방어력 | 런 패시브 + 영구 패시브 | 받는 피해 감소 (최대 90%) |
| 쿨타임 감소 | 런 패시브 + 영구 패시브 | 모든 무기 쿨타임에 곱연산 적용 |
| 자석 | 영구 패시브 | 경험치/골드 픽업 자동 흡인 반경 |
| 행운 | 런 패시브 | 스탯만 존재 — 소비하는 시스템은 아직 없음(드랍률 등 연동은 추후 과제) |
| 투사체 증가 | 런 패시브 | 발사체/공전형 무기의 개수 +1 (레벨당) — 여러 무기가 공용으로 소비하는 범용 스탯 |
| 범위 증가 | 런 패시브 | 범위형 무기의 반경 +15% (레벨당) — 여러 무기가 공용으로 소비하는 범용 스탯 |
| 관통력 | 런 패시브 + 영구 패시브 | 카드/상점 모두 하나만 존재하지만, 올리면 물리관통력·마법관통력이 동시에 오름(내부적으로는 두 스탯으로 분리 관리 — 나중에 적별 물리/마법 방어를 따로 조절하거나 특정 무기에만 관통력을 붙이는 등 벨런싱 확장을 위한 사전 설계) |

**런 패시브**와 **영구 패시브**는 이름은 비슷하지만 완전히 별개 시스템이다.
- **런 패시브**: 레벨업 카드로 뽑아서 무기 카드와 같은 풀에서 섞여 나오고, 이번 판이 끝나면 초기화된다.
- **영구 패시브**: 골드로 타이틀 화면 상점에서 구매하고, `PlayerPrefs`에 영구 저장되어 다음 판에도 유지된다.

레벨업 카드 3장을 뽑을 때 **이미 레벨이 오른(투자한) 무기/패시브에는 가중치를 더 줘서** 먹었던 걸 더 잘 뽑히게 한다 — 이것저것 다 찍먹하기보다 한 무기를 밀어서 키우는 선택도 유효한 전략이 되도록 하기 위함.

## 웨이브 & 보스

한 판은 10분이며, 시간 흐름에 따라 난이도가 계단식으로 올라간다.

- **상시 스폰**: 기본(0초~) → 빠름(90초~) → 탱커(240초~) 순으로 등장 적 종류가 누적되고, 스폰 간격은 1.5초에서 0.5초까지(480초에 걸쳐) 점점 빨라진다. 적 체력은 최대 2.5배, 물리 방어력과 마법 방어력 모두 최대 25%까지(600초에 걸쳐) 함께 증가한다 — 두 방어력을 분리해 둔 덕분에 마법사 진화(관통력)의 실효성이 시간이 지날수록 의미를 갖는다.
- **대규모 웨이브**: 3/6/9분마다 화면에 "WAVE n" 안내와 함께 적이 한 번에 대량 스폰된다(8→14→20마리로 회차마다 증가). 상시 스폰과 별개로 추가되는 물량이다.
- **보스**: 10분 시점에 "BOSS" 안내와 함께 보스가 등장하고, 화면 상단에 전용 체력바가 뜬다. 이 시점부터는 **10분 생존이 아니라 보스 처치가 클리어 조건**이며, 보스 등장 후에도 기존 잡몹 스폰은 계속되어 보스와 잡몹을 동시에 상대해야 한다. 보스는 추적+접촉 데미지에 더해 주기적으로 원형 경고 후 넓은 범위를 타격하는 슬램 공격을 쓴다(경고 범위와 실제 판정 범위가 정확히 일치).
- 웨이브/보스 스폰은 모두 `EnemySpawner`가 소유하며, 이벤트(`OnWaveTriggered`/`OnBossSpawned`)로 `GameManager`(클리어 판정)와 UI(안내 배너, 보스 체력바)에 알린다 — 스포너는 "언제 무엇이 나오는지"만 책임지고, 그에 대한 반응(승리 조건, 화면 연출)은 전부 구독자 쪽에서 처리한다.

## 결과 화면 / 타이틀 화면

- **결과 화면**: 생존 시간 표시 + "다시 시작"(같은 씬 재시작) / "타이틀로"(타이틀 씬 이동) 버튼.
- **타이틀 화면**: 캐릭터 3종 동적 목록(해금 여부에 따라 "선택"/"선택됨"/"해금" 버튼 전환), 보유 골드 표시, 골드 상점(영구 패시브 8종 동적 목록), "게임 시작", 테스트용 "초기화"(`PlayerPrefs.DeleteAll`) 버튼.
- 캐릭터 목록과 상점 목록 모두 같은 `ShopSlot` 프리팹을 재사용하는 동적 리스트라 항목이 늘어나도 UI를 손댈 필요가 없다.

## 피드백/연출

- 전방 베기·보스 슬램의 판정 범위는 절차적으로 생성한 부채꼴/원형 메쉬로 표시 — 스프라이트로 대충 흉내내지 않고 실제 `Physics2D.OverlapCircleAll` 판정 반경·각도와 정확히 같은 도형을 매 공격마다 그려서, 시각적으로 보이는 범위와 실제 맞는 범위가 절대 어긋나지 않는다(추후 최종 스프라이트로 교체 예정인 임시 색상 도형).
- 적이 데미지를 받으면 머리 위로 데미지 숫자가 떠올랐다 서서히 사라짐(`TextMesh` 기반 월드 스페이스 텍스트, 로그가 아니라 실제 화면 표시).
- 구르기(액티브 스킬)는 화면 우하단 버튼으로 발동하며, 같은 버튼이 쿨타임 원형 게이지 역할도 겸한다(쿨타임 중엔 비활성화) — 해당 무기가 없는 캐릭터로 플레이할 땐 자동으로 숨겨진다.
- 대규모 웨이브/보스 등장 시 화면 중앙에 "WAVE n"/"BOSS" 문구가 떴다 서서히 사라지는 안내 배너.
- 보스 등장 시에만 나타나는 전용 체력바(평소엔 숨겨져 있다가 보스가 스폰되는 순간 바인딩되어 표시).
- **개발 편의**: 에디터에서 F1을 누르고 있으면 시간 배속(10배) — 10분짜리 판을 매번 실시간으로 기다리지 않고 웨이브/보스 타이밍을 빠르게 테스트하기 위한 전용 도구(`#if UNITY_EDITOR`로 감싸 실제 빌드에는 포함되지 않음).

- **런 패시브 / 영구 패시브 분리**: 이번 판 한정 스탯 강화(레벨업 카드)와 세션 간 영구 강화(골드 상점)를 구조적으로 분리
- **범용 투사체/범위 패시브**: "투사체 증가"/"범위 증가"를 여러 무기가 공용으로 소비하도록 설계해, 새 무기를 추가해도 기존 패시브가 자동으로 적용됨
- **타이틀 화면**: 캐릭터 선택/해금 + 골드 상점을 결과 화면에서 분리해 별도 씬으로 이동
- **웨이브 & 보스**: 3/6/9분 대규모 웨이브 + 10분 보스 등장, 보스 처치를 클리어 조건으로 변경, 보스 전용 슬램 패턴·체력바·안내 배너
- **자석, 데미지 숫자 팝업, 구르기 쿨타임 게이지** 등 QoL/피드백 요소
- **무기 진화**: 9개 무기 전부 레벨 8(만렙) 도달 시 강제로 등장하는 진화 카드로 완전히 다른 무기로 전환(레벨 1부터 재성장) — 물리/마법 방어력 분리, 관통력 스탯, 적 임시 디버프(둔화/빙결/발화/독), 진화 전후로 끊김 없는 액티브 스킬 UI 분리(구르기), 임시 버프 시스템(블레싱) 등 새 인프라를 이 과정에서 함께 구축
