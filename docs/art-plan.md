# Swarm 아트 조달 계획

**우선순위: 개발 속도 > 아트 완성도.** 이 프로젝트는 클라이언트 개발자 포트폴리오이자 1개월 타이트 스코프이므로, 게임플레이 시스템 구현이 핵심이고 아트는 "있으면 좋은" 영역으로 취급한다. 손그림 픽셀 아트는 기본 경로에서 제외하고, 무료 에셋으로 먼저 게임을 완성한 뒤 여유가 있을 때만 선택적으로 교체한다.

---

## 1. 기본 전략: 무료 에셋 우선 조달

| 분류 | 조달 방법 |
|------|-----------|
| 플레이어 | 무료 탑다운 캐릭터 스프라이트(Idle/Walk) |
| 적 3종 (기본/빠름/탱커) | 무료 팩에서 색·크기로 구분되는 유닛 선택, 없으면 같은 스프라이트 틴트(Color) 차등으로 대체 |
| 무기 이펙트 (근접/투사체/범위) | 무료 이펙트 스프라이트 또는 Unity 기본 Shuriken Particle System으로 대체 |
| UI (HP 바, 경험치 바, 타이머, 카드 아이콘) | 무료 UI 팩, 필요시 Unity 기본 도형(Image 색상 채우기)으로 임시 대체 |
| 타일맵/배경 | 무료 탑다운 타일셋 |

**소싱 후보**: Unity Asset Store 무료 카테고리, Kenney 계열 CC0 에셋, itch.io 무료 게임 에셋 팩. 실제 다운로드는 사용자가 직접 진행.

---

## 2. 스타일 통일 원칙

- 여러 팩을 섞으면 캔버스 크기·픽셀 밀도·팔레트가 어긋나 한 화면에서 이질감이 생김.
- **플레이어 + 적 3종 + 무기 이펙트는 가능한 한 하나의 통일된 탑다운 서바이버 스타일 팩**에서 가져온다.
- UI/타일맵은 별도 소스를 써도 무방 (플레이 중 직접 비교되는 영역이 아님).

---

## 3. 라이선스 체크리스트 (필수)

포트폴리오/구직용으로 공개될 프로젝트이므로 에셋 도입 전 반드시 확인:

- [ ] 상업적 이용(포트폴리오 공개, 취업 지원용 시연) 허용 여부
- [ ] 출처 표기(attribution) 의무 여부 → 있다면 크레딧 화면/README에 기재
- [ ] 재배포·수정 제한 여부
- [ ] 라이선스 원문 또는 링크를 프로젝트 내 기록 (예: `Assets/_Project/Textures/LICENSES.md` 등)으로 남겨두기

## 4. 제작 순서 (수정판)

| 시점 | 아트 작업 |
|------|-----------|
| Week1~2 (코드 병행) | 스타일 통일된 무료 팩 탐색·선정, 플레이어/적/이펙트 임포트 |
| Week3 | UI/타일맵 무료 에셋 적용, 부족한 부분만 추가 소싱 |
| Week4 | 버그 수정·빌드 우선. 시간이 남을 때만 아래 5번(선택 사항) 진행 |

무료 에셋으로 먼저 전체 루프(이동→전투→레벨업→웨이브→결과 화면)를 완성하는 것이 목표. 아트 완성도 때문에 기능 구현 일정이 밀리지 않도록 한다.

---

## 5. (선택 사항) 손그림 아트 폴리싱

시간이 남을 경우에만 진행하는 스트레치 목표. 우선순위는 낮음 — 게임 완성이 우선.

- 대상: 플레이어 캐릭터 1종 정도만 (가장 자주 보이는 스프라이트라 교체 효과가 가장 큼)
- 툴: Aseprite(유료, `com.unity.2d.aseprite` 임포터 패키지 설치되어 있어 `.aseprite` 파일 바로 임포트 가능) 또는 무료 대안(Piskel, LibreSprite)
- 캔버스 크기: 16×16 또는 24×24px, 팔레트 4~8색으로 제한
- Aseprite → Unity 연동: 태그별(`Idle`, `Walk`)로 애니메이션 나눠 작업 → Import Settings에서 `Generate Animation Clips` 체크 → 태그별 AnimationClip 자동 생성
